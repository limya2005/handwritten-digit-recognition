# Handwritten Digit Recognition

## About the Project
This project recognizes handwritten numbers from 0 to 9 using Deep Learning.

## Technologies Used
- Python
- TensorFlow
- Keras
- MNIST Dataset
- Matplotlib

## How It Works
1. Load the MNIST dataset.
2. Prepare the images.
3. Build a neural network.
4. Train the model.
5. Test the model.
6. Predict the handwritten digit.

## Project Flow
Image → Neural Network → Prediction → Digit

## Result
The trained model predicts handwritten digits from 0 to 9.
